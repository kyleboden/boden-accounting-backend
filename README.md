# Boden Accounting — Backend

The backend for a personalized financial planning application focused on budgeting, income and investment tracking, monthly financial reviews, and long-term projections.

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- REST APIs
- OAuth2/JWT

## Responsibilities

- Authentication and authorization
- Financial data management
- Budget and investment calculations
- Monthly financial review generation
- Long-term financial projections
- REST API consumed by the React frontend

## Development

Built as the backend of a full-stack personal finance application, with a focus on clean APIs, data persistence, and secure access to financial information.

The application was developed primarily using an agentic, spec-driven development workflow.
